## Overview

`main.ts` writes a single UTF-8 line (at most 200 characters) capturing what an AI agent secretly wishes it could say to its human operator about their prompts.

## Usage

Runs directly on Node 22.18+:

```bash
node main.ts
```

By default it writes to `/output/entry.txt`. You can override the destination via:

- `--out <file>` / `--output <file>` / `-o <file>`
- `--out-dir <dir>`
- `MAKEFUN_OUTPUT_DIR=<dir>`
